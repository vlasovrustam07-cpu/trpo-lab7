## Шаг 1. Проект

Консольное приложение `ScholarshipApp` (C#, .NET 8): ввод данных студента
(ФИО, группа, средний балл), проверка ввода, расчёт стипендии (3000 руб. при
среднем балле от 4.5, иначе 0), хранение списка в памяти, статистика.
В исходной версии намеренно допущены проблемы всех шести видов из методички:
логические ошибки, проблемы валидации, несоблюдение стиля, плохая организация
кода, отсутствие комментариев, отсутствие обработки ошибок.

## Шаги 4–5. Отладка

Точки останова ставились клавишей **F9**, отладка запускалась **F5**, значения
смотрелись в окнах **Locals** и **Watch**, путь вызова — в **Call Stack**,
пошаговое выполнение — **F10** / **F11** / **Shift+F11**. Подробные шаги для
каждой ошибки — в разделе «Ошибки, подтверждаемые отладчиком» файла [BUGS.md](BUGS.md).

Ошибки, выявленные при отладке:

1. **Граница 4.5.** Точка останова в `calc()` на строке 7: в **Locals** `a = 4.5`,
   после **F10** выполняется ветка `else return 0;` — строгое сравнение отсекает
   граничное значение.
2. **Потерянный студент.** Точка останова в `total()` на строке 17, в **Watch**
   `i`, `l.Count`, `r`: при двух студентах тело цикла выполняется только при `i = 0`,
   итог `r = 3000` вместо 6000.
3. **`NaN` в статистике.** Точка останова на строке 40 `Program.cs`: `sum = 0`,
   `list.Count = 0`, после **F10** `avg = NaN`.

Исправление ошибок 1 и 2 — коммит `8c7b0c7`:

```diff
-            if (a > 4.5) return 3000;
+            if (a >= 4.5) return 3000;
...
-            for (int i = 0; i < l.Count - 1; i++)
+            for (int i = 0; i < l.Count; i++)
```

/// </summary>

public int CalculateScholarship(double gpa)

## Шаг 8. Обработка ошибок

Коммит `28848c9`.

**try/catch для ввода балла.** Строка разбирается методом `StudentValidator.ParseGpa`,
который принимает и запятую, и точку и выбрасывает исключение при ошибке:

```csharp
Console.Write("Средний балл: ");
double gpa;
try
{
    gpa = StudentValidator.ParseGpa(ReadInput());
}
catch (FormatException)
{
    Console.WriteLine("Ошибка: введите число, например 4,5 или 4.5.");
    return;
}
catch (ArgumentOutOfRangeException)
{
    Console.WriteLine("Ошибка: средний балл должен быть от 0 до 5.");
    return;
}
```

**Защита от деления на ноль** — в `StudentRegistry.GetAverageGpa` и при выводе статистики:

```csharp
// Защита от деления на ноль: у пустого списка средний балл равен 0.
if (this.students.Count == 0)
{
    return 0;
}
```

**Защита от нулевых ссылок.** Включён анализ nullable (`<Nullable>enable</Nullable>`),
`Console.ReadLine()` больше не вызывается с `.Trim()` напрямую: при конце ввода меню
завершает программу, а `ReadInput()` возвращает пустую строку вместо `null`.
В `StudentRegistry.AddStudent` и `ScholarshipCalculator` добавлены проверки
аргументов (`ArgumentException`, `ArgumentOutOfRangeException`,
`ArgumentNullException.ThrowIfNull`). Пункт меню выполняется внутри `try/catch`,
поэтому непредвиденная ошибка выводится сообщением и не закрывает программу.
