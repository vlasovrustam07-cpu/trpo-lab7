## Ошибки, подтверждаемые отладчиком (шаги 4–5)

Чтобы повторить отладку в Visual Studio, переключитесь на исходную версию:
`git checkout v1-buggy`, откройте `ScholarshipApp.sln`.

### Баг 1 — граница 4.5

1. Откройте `ScholarshipCalculator.cs`, поставьте точку останова (**F9**) на строке 7
   `if (a > 4.5) return 3000;`.
2. Запустите отладку (**F5**), выберите пункт `1`, введите ФИО `Иванов Иван`,
   группу `ИСТ-21`, балл `4,5` (в русской Windows дробная часть вводится через запятую).
3. В окне **Locals** видно `a = 4.5`. Нажмите **F10**: выполнение уходит в ветку
   `else return 0;` — условие `4.5 > 4.5` ложно.
4. В окне **Call Stack**: `ScholarshipCalculator.calc` вызван из `Program.Main`.

**Вывод:** граничное значение 4.5 не проходит из-за строгого сравнения, нужно `>=`.

### Баг 2 — потерянный студент в фонде стипендий

1. Поставьте точку останова на строке 17 `r = r + l[i].st;` в `ScholarshipCalculator.cs`.
2. Добавьте двух студентов с баллами `5` и `4,8`, затем выберите пункт `3`.
3. Добавьте в окно **Watch** выражения `i`, `l.Count`, `r`. Нажимайте **F10**:
   тело цикла выполняется только при `i = 0`, затем условие `i < l.Count - 1`
   (`1 < 1`) ложно, и второй студент не учитывается: `r = 3000`.

**Вывод:** граница цикла должна быть `i < l.Count`.

### Баг 3 — `NaN` для пустого списка

1. Поставьте точку останова в `Program.cs` на строке 40 `double avg = sum / list.Count;`.
2. Сразу выберите пункт `3`. В **Locals**: `sum = 0`, `list.Count = 0`.
   После **F10**: `avg = NaN`.

**Вывод:** перед делением нужна проверка на пустой список.
